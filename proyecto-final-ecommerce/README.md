# Tienda Sol - Proyecto final de e-commerce

Proyecto realizado para la Clase 6 de Desarrollo de Sistemas Web.

## Funcionalidades

- Productos cargados desde una API REST.
- Renderizado dinamico con JavaScript.
- Busqueda, filtro por categoria y ordenamiento.
- Carrito de compras editable.
- Persistencia del carrito con `localStorage`.
- Simulacion de compra.
- Formulario de contacto preparado para Formspree.
- Diseno responsive con Bootstrap y Flexbox.
- Etiquetas semanticas, textos alternativos, foco visible y metadatos SEO.

## Importante para entregar

1. Crear una cuenta/proyecto en Formspree.
2. Reemplazar `https://formspree.io/f/tu-id-formspree` en `index.html` por el endpoint real.
3. Completar `GrupoX.txt` con integrantes, repositorio y GitHub Pages.
4. Renombrar `GrupoX.txt` reemplazando `X` por el numero de grupo.
